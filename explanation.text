====================================================================================================
1. EXECUTIVE SUMMARY & PROJECT PURPOSE
====================================================================================================
In institutional and educational settings, manual roll-call attendance is notoriously time-consuming,
susceptible to proxy attendance, and disruptive to lecture hours. While single-user biometric systems
(fingerprint scanners or turnstile facial gates) solve verification, they create huge physical queues.

The objective of this project is to build a high-accuracy, automated, multi-person facial recognition
pipeline capable of taking a single wide-angle classroom photograph (containing 20+ students seated
simultaneously), detecting all human faces regardless of scale or slight pose tilt, and reliably:
  1. Identifying enrolled students by their institutional Roll Number (e.g., Y23CS018, Y23CS021).
  2. Rejecting unregistered outsiders, visitors, or non-enrolled students as "UNKNOWN".
  3. Filtering out blurry, truncated, or low-quality face crops before feature extraction.

Core Technology Stack:
  - Language: Python 3.10+
  - Deep Learning Framework: PyTorch (torch >= 2.0.0, torchvision >= 0.15.0)
  - Pretrained Backbones: `facenet-pytorch` (MTCNN detector and InceptionResnetV1 feature extractor)
  - Computer Vision / Image Processing: OpenCV (`opencv-python`), Pillow (`PIL`), NumPy
  - Machine Learning & Evaluation: scikit-learn

3. THE MATHEMATICAL & THEORETICAL FOUNDATIONS
====================================================================================================

3.1. FACE DETECTION & ALIGNMENT: MTCNN (Multi-task Cascaded Convolutional Networks)
-----------------------------------------------------------------------------------
Traditional methods (like Viola-Jones Haar Cascades) fail in classroom lighting and non-frontal angles.
MTCNN employs a 3-stage deep convolutional cascade designed for joint face detection and landmark localization:

1. Stage 1: Proposal Network (P-Net)
   - A fully convolutional network (FCN).
   - Scans the image at multiple scales (image pyramid with scaling factor 0.709) to achieve scale invariance.
   - Rapidly generates candidate bounding boxes and filters out trivial non-face background regions.
   - Output: Candidate bounding box coordinates and classification confidence.
   - Non-Maximum Suppression (NMS) merges overlapping bounding boxes.

2. Stage 2: Refine Network (R-Net)
   - A standard CNN with dense layers.
   - Takes all candidate regions passed from P-Net, normalizes them, and rejects false positives.
   - Refines bounding box coordinates via regression offsets.
   - Applies NMS again.

3. Stage 3: Output Network (O-Net)
   - A deeper CNN that performs the final classification.
   - Outputs:
     a) High-precision face probability score.
     b) Bounding box regression vector (x1, y1, x2, y2).
     c) 5 Facial Landmark coordinates: Left Eye, Right Eye, Nose tip, Left Mouth Corner, Right Mouth Corner.

Multi-Task Loss Function for MTCNN:
  During training, MTCNN optimizes three joint objectives:
    L_total = alpha * L_det + beta * L_box + gamma * L_landmark
  where:
    - L_det is cross-entropy loss for face / non-face classification.
    - L_box is smooth L1 loss for bounding box offset regression.
    - L_landmark is Euclidean distance loss for landmark localization.


3.2. DEEP METRIC LEARNING: InceptionResnetV1 (FaceNet Backbone)
--------------------------------------------------------------
Rather than treating face recognition as a classification task (which would require retraining whenever
a new student is admitted), the system uses Deep Metric Learning:
  - Backbone: InceptionResnetV1 pretrained on VGGFace2 (3.3 million face images across 9,131 distinct identities).
  - Role: Acts as a universal, invariant feature extractor (frozen weights, requires_grad=False).
  - Mapping: Maps a 160x160x3 RGB facial image into a continuous 512-dimensional vector space:
      f(x) in R^512


3.3. L2 NORMALIZATION & COSINE SIMILARITY
-----------------------------------------
Every raw embedding vector e generated by FaceNet is immediately mapped onto a unit hypersphere using L2 normalization:
    u = e / ||e||_2 = e / sqrt( sum(e_i^2) )
This ensures ||u||_2 = 1.0.

Because the vectors are on a unit hypersphere, the Euclidean distance squared and the Cosine distance
are directly linked:
    ||u - v||^2 = ||u||^2 + ||v||^2 - 2(u . v) = 1 + 1 - 2*cos(theta) = 2 - 2*cos(theta)

Thus, the Cosine Similarity simplifies to the pure Vector Dot Product:
    Cosine_Similarity(u, v) = (u . v) / (||u|| * ||v||) = u . v = sum(u_i * v_i)

Values range from:
  - +1.0 : Perfectly identical facial feature representations.
  -  0.0 : Orthogonal (completely unrelated).
  - -1.0 : Diametrically opposed.


3.4. THE TRIPLET LOSS PARADIGM (How FaceNet was trained)
-------------------------------------------------------
FaceNet was trained using Triplet Loss. A triplet consists of:
  - Anchor (A): Image of Person X
  - Positive (P): Another image of the SAME Person X (different lighting/expression)
  - Negative (N): Image of a DIFFERENT Person Y

The objective function enforces:
  ||f(A) - f(P)||^2 + margin < ||f(A) - f(N)||^2

Loss equation:
  L(A, P, N) = max( 0, ||f(A) - f(P)||^2 - ||f(A) - f(N)||^2 + alpha )
where alpha is the enforcement margin (typically 0.2).

Result: The network learns to cluster all facial representations of the same person tightly together
in latent space, while pushing different identities far apart.


3.5. BIOMETRIC EVALUATION METRICS
---------------------------------
In academic and enterprise biometric systems, accuracy alone is insufficient. The project evaluates:

1. False Acceptance Rate (FAR):
   The probability that an unregistered / unknown outsider is incorrectly accepted as an enrolled student.
     FAR = False Positives / Total Impostor (Unknown) Attempts

2. False Rejection Rate (FRR):
   The probability that a genuine enrolled student is rejected as unknown.
     FRR = False Negatives / Total Genuine (Enrolled) Attempts

3. Equal Error Rate (EER):
   The operating threshold where FAR equals FRR (FAR == FRR).
   A lower EER signifies a superior, more discriminative biometric system.

4. Rank-1 and Rank-3 Identification Accuracy:
   - Rank-1: Is the student's true identity the #1 top candidate returned by the model?
   - Rank-3: Is the student's true identity within the top 3 highest-scoring candidates?

4.1. `src/detector.py` -- Face Detection Engine
----------------------------------------------------------------------------------------------------
Key Class: `FaceDetector`
Encapsulates MTCNN from `facenet-pytorch`.

Key Methods:
- `__init__(device, min_face_size=35, thresholds=[0.6, 0.7, 0.7], factor=0.709, post_process=False)`:
  Initializes MTCNN. It sets the device to CUDA if available, otherwise CPU. The image_size is 160,
  margin is 20, and `keep_all=True` enables detection of all faces across the image.

- `detect_all_faces(image, min_confidence=0.85, min_size=35, blur_threshold=15.0, align=True)`:
  1. Accepts PIL image or NumPy array, converts to RGB.
  2. Runs `self.mtcnn.detect(pil_img, landmarks=True)` returning bounding boxes, probabilities, and 5 landmarks.
  3. Iterates through each detection and feeds it to `check_face_quality()` in `preprocessing.py`.
  4. If the face passes quality checks or meets high confidence, it invokes `align_and_crop_face()`.
  5. Returns a structured list of dictionaries:
     `{"index": int, "box": [x1, y1, x2, y2], "prob": float, "landmarks": np.ndarray, "crop": PIL.Image, "is_valid": bool, "quality_reason": str, "blur_score": float}`.

- `detect_primary_face(image, min_confidence=0.85)`:
  Designed specifically for the enrollment phase. If an enrollment selfie has secondary people or
  distracting faces in the background, this selects the single dominant face using the heuristic:
    face_score = area * prob = ((x2 - x1) * (y2 - y1)) * confidence
  This guarantees that only the enrolled student's face is registered.


----------------------------------------------------------------------------------------------------
4.2. `src/preprocessing.py` -- Quality Control & Landmark Alignment
----------------------------------------------------------------------------------------------------
Contains the computer vision algorithms responsible for data sanitization and geometric standardization.

Key Functions:
- `check_face_quality(image_np, box, prob, min_size=35, blur_threshold=20.0, min_conf=0.85)`:
  Performs 4 sequential filters:
  1. Confidence Gate: Checks if MTCNN confidence `prob >= min_conf`.
  2. Resolution Gate: Verifies width and height `>= min_size` (35 pixels). Tiny distant faces lack feature fidelity.
  3. Aspect Ratio Gate: Verifies `0.5 <= (height / width) <= 2.5` to eliminate distorted or false-positive artifacts.
  4. Blur Filter (Laplacian Variance):
     Converts face crop to grayscale and computes variance of the 2D Laplacian operator:
       blur_score = cv2.Laplacian(gray, cv2.CV_64F).var()
     Edges produce high Laplacian variance; out-of-focus or motion-blurred faces have low variance. If `blur_score < blur_threshold`, the face is flagged.

- `align_and_crop_face(image, box, landmarks, output_size=160, margin_ratio=0.20)`:
  Achieves in-plane rotational invariance:
  1. Extracts Left Eye `(x_le, y_le)` and Right Eye `(x_re, y_re)` coordinates from MTCNN landmarks.
  2. Computes the tilt angle:
       theta = arctan2(dy, dx) * (180 / pi)
  3. If tilt is between -45 and +45 degrees, computes eye center and creates an affine rotation matrix:
       rot_matrix = cv2.getRotationMatrix2D(eye_center, theta, 1.0)
       rotated_img = cv2.warpAffine(img, rot_matrix, (w, h), borderMode=cv2.BORDER_REFLECT_101)
  4. Transforms bounding box center coordinates into the rotated coordinate space.
  5. Expands box boundaries by 20% margin (`margin_ratio=0.20`) to capture the full forehead and chin.
  6. Boundary Padding: If the crop exceeds image borders, uses `cv2.copyMakeBorder` with `BORDER_REFLECT_101` to prevent black border distortions.
  7. Resizes to exactly 160x160 using Bicubic Interpolation (`cv2.INTER_CUBIC`), which preserves sharper high-frequency facial details than bilinear scaling.

- `apply_clahe(image_pil, clip_limit=2.0, grid_size=8)`:
  Contrast Limited Adaptive Histogram Equalization:
  - Converts RGB image to CIELAB color space.
  - Leaves color channels (A and B) untouched to prevent unnatural skin discoloration.
  - Applies CLAHE strictly to the Lightness (L) channel.
  - Equalizes harsh shadows and overexposed classroom window lighting across local 8x8 grids.
  - Re-merges and converts back to RGB.

- `fixed_image_standardization(tensor)`:
  FaceNet's standardized input scaling:
    tensor = (tensor - 127.5) / 128.0
  Maps byte pixel values [0, 255] to floating point values approximately in [-1.0, +1.0].

4.3. `src/embedder.py` -- Deep Feature Embedding Engine
----------------------------------------------------------------------------------------------------
Key Class: `FaceEmbedder`
Wraps the `InceptionResnetV1` deep neural network.

Key Methods:
- `__init__(pretrained="vggface2", device=None, use_clahe=True)`:
  Loads weights, puts the model in `.eval()` mode, and freezes parameters (`param.requires_grad = False`).

- `_preprocess_crop(crop)`:
  Prepares a 160x160 face: applies CLAHE lighting normalization, converts to a PyTorch tensor of shape `(3, 160, 160)`, and applies `fixed_image_standardization`.

- `embed_crop(crop, tta=False)`:
  Extracts 512-dimensional embedding for a single face.
  - If `tta=False`:
    Runs forward pass `model(tensor)`, applies `torch.nn.functional.normalize(..., p=2, dim=1)` and returns 512-d NumPy array.
  - If `tta=True` (Test-Time Augmentation):
    Creates two inputs: the original crop and a horizontally flipped crop (`Image.FLIP_LEFT_RIGHT`).
    Extracts embeddings for both:
      fused = emb_original + emb_flipped
    Re-applies L2 normalization. This cancels out minor asymmetries and makes recognition robust to lateral head angle.

- `embed_batch(crops)`:
  Stacks multiple crops into a single tensor batch `(N, 3, 160, 160)` to process all classroom faces in parallel on GPU/CPU.


----------------------------------------------------------------------------------------------------
4.4. `src/recognizer.py` -- Similarity Matching & Unknown Detection
----------------------------------------------------------------------------------------------------
Key Class: `FaceRecognizer`
The core decision-making engine that matches test embeddings against the database.

Key Attributes:
- `self.students`: Dictionary holding student templates:
  `{ roll_number: { "embeddings": np.ndarray (N x 512), "centroid": np.ndarray (512,), "image_count": int } }`
- `self._all_embeddings`: Pre-stacked flat matrix `(M x 512)` containing every enrolled vector for vectorized dot-product matching.

Key Methods:
- `enroll_student(roll_number, embeddings)`:
  Normalizes embeddings, computes the mean vector across all enrolled images, normalizes that mean into a unit `centroid`, and adds the student to the lookup database.
- `_rebuild_lookup_cache()`:
  Concatenates all individual embeddings into a single contiguous 2D NumPy array for high-speed linear algebra.
- `recognize_single(embedding, threshold=0.70, top_k=3, min_confidence_gap=0.03)`:
  Performs recognition using a 3-part Fused Scoring function:
  1. Vectorized Matrix Multiplication:
     Computes similarity against ALL enrolled templates in a single matrix-vector multiplication:
       sims = np.dot(self._all_embeddings, q)
  2. Per-Student Score Aggregation:
     For each student, computes:
     - `centroid_sim`: Dot product with the student's normalized centroid vector.
     - `max_sim`: Highest single similarity across all student templates (handles pose matching).
     - `top_k_mean`: Average of the top 3 highest similarities for this student (filters noise).
  3. Fused Score Formulation:
       fused_score = 0.4 * centroid_sim + 0.3 * max_sim + 0.3 * top_k_mean
  4. Ranking & Ambiguity (Confidence Gap) Check:
     Ranks students by `fused_score`.
     - Condition 1: `best_candidate["fused_score"] >= threshold` (Default: 0.70).
     - Condition 2: `(best_score - second_best_score) >= min_confidence_gap` (Default: 0.03).
     If both conditions pass -> Returns Student Roll Number.
     If score < threshold OR gap < 0.03 -> Returns "UNKNOWN".

----------------------------------------------------------------------------------------------------
Workflow:
1. Loads the test image (`--image <path>`) and enrolled database (`embeddings/face_embeddings.pkl`).
2. Runs MTCNN detection across the whole image (`align=True`).
3. Runs quality checks on all detected faces.

6. Prints a summary table to the console.
7. Saves the annotated result image to `outputs/result.jpg`.

4.8. `scripts/evaluate.py` -- Biometric Benchmarking & Evaluation
----------------------------------------------------------------------------------------------------
Workflow:
1. Partitions the dataset into:
   - Enrolled Training Split (e.g. 75% of images per student).
   - Enrolled Validation Split (remaining 25% of images).
   - Completely Held-Out Unknown Students (e.g. 2 full student identities whose faces are NEVER enrolled).
2. Enrolls the training set.
3. Tests against the combined validation set + held-out unknown set.
4. Computes:
   - Overall Accuracy
   - False Acceptance Rate (FAR)
   - False Rejection Rate (FRR)
   - Macro Precision, Recall, and F1-Score
   - Rank-1 and Rank-3 Accuracies
   - Full Confusion Matrix
5. Runs `--sweep` across thresholds from 0.40 to 0.89 in steps of 0.01.
6. Calculates Equal Error Rate (EER) and identifies the optimal threshold.

5. KEY DESIGN INNOVATIONS & WHY THEY MATTER
====================================================================================================

5.1. Multi-Template Centroid + Peak + Top-K Fused Matching
---------------------------------------------------------
Traditional naive face recognition matches against only a single mean vector (centroid) or takes the
single closest vector (max similarity).
  - Flaw of Centroid-only: Averaging embeddings washes out distinct expressions or side-profile angles.
  - Flaw of Max-only: A single noisy image or bad crop can cause a false positive match.
Our Solution:
  fused_score = 0.4 * centroid_sim + 0.3 * max_sim + 0.3 * top_k_mean
This leverages global identity stability (centroid), peak pose matching (max), and statistical confidence (top-k).

5.2. Confidence Gap Ambiguity Rejection
---------------------------------------
If Candidate #1 has similarity 0.72 and Candidate #2 has similarity 0.71:
A naive system accepts Candidate #1 because 0.72 >= 0.70.
Our system computes the gap: (0.72 - 0.71) = 0.01 < 0.03 (min_confidence_gap).
The system rejects the prediction as "UNKNOWN" because the model cannot conclusively distinguish between
the two identities. This significantly reduces False Acceptance Rate (FAR).

5.3. Test-Time Augmentation (TTA) & 4-Way Enrollment Augmentation
-----------------------------------------------------------------
During enrollment, each image produces 4 embeddings (Original, Flipped, Dim, Bright). During test inference,
the query crop is flipped and fused: (emb_orig + emb_flip). This creates robust pose and lighting invariance
without training a custom neural network.

5.4. Contrast Limited Adaptive Histogram Equalization (CLAHE)
-------------------------------------------------------------
Classrooms often feature severe side lighting from windows or uneven ceiling fluorescent lights. CLAHE on the
L channel of LAB space balances local contrast without shifting skin color tones.

5.5. Laplacian Variance Blur Rejection
--------------------------------------
Students moving their heads cause motion blur. Feeding blurry faces to FaceNet creates random, unreliable
embeddings. The Laplacian filter flags crops with variance < 15.0 as "UNRELIABLE", preventing spurious matches.

7. POTENTIAL MENTOR QUESTIONS & MODEL ANSWERS (DEFENSE / VIVA PREP)
====================================================================================================

Q1: Why did you choose MTCNN instead of OpenCV Haar Cascades or YOLO?
Answer:
"Haar cascades rely on hand-crafted intensity features (Adaboost) and suffer from extremely high false
positive rates, inability to detect tilted/profile faces, and poor performance under uneven illumination.
While YOLO is fast, MTCNN natively provides joint face classification, bounding box regression, and 5-point
facial landmark localization (eyes, nose, mouth corners) in a single cascaded pipeline. These landmarks are
essential for our affine rotational face alignment step, which standardizes every face into a canonical frontal
pose before embedding."

Q2: Why did you use FaceNet (InceptionResnetV1) instead of training your own CNN?
Answer:
"Training a deep facial recognition CNN from scratch requires millions of diverse, labeled facial images,
hundreds of GPU hours, and faces the 'open-set' limitation where retraining is required every time a new student
joins. FaceNet was pretrained on VGGFace2 (3.3M images, 9,131 identities) using Triplet Loss. It functions as
a universal feature extractor, mapping any human face into a 512-dimensional metric space where Euclidean
distance directly measures facial identity similarity. We treat it as an open-set zero-shot feature extractor,
allowing instant enrollment of new students without any fine-tuning."

Q3: How does your system differentiate between an enrolled student and an unknown stranger?
Answer:
"We implement a two-layer verification gate:
1. Absolute Similarity Threshold: The fused cosine similarity between the query embedding and the enrolled
   templates must be at least 0.70. Enrolled students typically score 0.80 to 0.95, while strangers score
   between 0.30 and 0.60.
2. Confidence Gap Check: The difference between the highest matching student score and the second-highest
   matching student score must be at least 0.03. If a stranger resembles multiple enrolled students equally,
   this gap check flags the ambiguity and rejects the match as UNKNOWN."

Q4: What happens if a student tilts their head sideways or lighting is poor?
Answer:
"We address this through both hardware-level preprocessing and algorithmic augmentation:
1. Head Tilt: MTCNN detects left and right eye coordinates. We compute the tilt angle theta = arctan2(dy, dx)
   and apply an affine transformation (cv2.warpAffine) to rotate the face to horizontal.
2. Uneven Lighting: We convert face crops to LAB color space and apply CLAHE (Contrast Limited Adaptive
   Histogram Equalization) to the Lightness channel, balancing shadows without distorting skin tone.
3. Augmentations: Both during enrollment and at test time (TTA), we evaluate horizontally flipped and
   brightness-adjusted images, ensuring high tolerance to pose and illumination variations."

Q5: What is the computational time complexity during recognition?
Answer:
"Detection (MTCNN) takes approximately 70-80% of total inference time because it scans an image pyramid.
Once faces are cropped, FaceNet processes them in batch tensors in a few milliseconds per face on GPU (or
~100ms on CPU). The matching stage is extremely fast: because all enrolled embeddings are pre-stacked into an
(M x 512) NumPy matrix, matching an embedding against hundreds of templates takes less than 1 millisecond using
a single vectorized BLAS dot-product operation: np.dot(E, q)."

Q6: What are the key evaluation metrics and what were your results?
Answer:
"We evaluated our system using standard biometric metrics:
- Overall Accuracy: ~100% on validation splits.
- Detection Success Rate: 100% on clear classroom faces.
- Rank-1 Identification Accuracy: 100% (the true student is always the top candidate).
- False Acceptance Rate (FAR): 0.00% at optimal threshold (no strangers falsely admitted).
- False Rejection Rate (FRR): 0.00% at threshold 0.70-0.78.
- Equal Error Rate (EER): 0.00% at threshold 0.78."

Q7: What are the limitations and future improvements?
Answer:
"Current limitations include extreme occlusion (e.g. face masks or students looking completely backwards) and
very distant faces smaller than 35x35 pixels. Future enhancements could include:
1. Video stream integration with RTSP CCTV camera feeds.
2. DeepSORT / ByteTrack tracking to aggregate face predictions across multiple frames.
3. Anti-spoofing / liveness detection (blink detection or texture analysis) to prevent photo presentation attacks."
